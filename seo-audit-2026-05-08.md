## CRITICAL — fix this week

### C1. Site-wide canonical / host mismatch
Every page's `<link rel="canonical">` and every URL inside `/sitemap.xml` points to bare `https://sarvaya.in/…`, but the bare host **308-redirects to `https://www.sarvaya.in/…`**. The robots.txt also declares `Sitemap: https://sarvaya.in/sitemap.xml`. Result: every canonical points to a URL that immediately redirects, and the sitemap is filled with redirected URLs. Google will treat this as a contradictory self-canonical signal.

**Fix (pick one):**
- Drop the www→bare redirect direction so `sarvaya.in` is the served canonical (matches every existing tag, simplest), **OR**
- Rewrite all canonicals + sitemap + robots Sitemap line + Organization `sameAs`/`@id` to `www.sarvaya.in`.

Don't do both halfway.

### C2. Fabricated-looking review schema on homepage
10 embedded `Review` objects (all 5★, dated through 2026-04-30, `publisher: Google`) sit in homepage JSON-LD, not pulled from the Google Reviews API. One review claims "40% conversion uplift". This is exactly the pattern Google calls out as policy-violating self-serving review markup → manual-action risk.

**Fix:** Remove the `Review[]` and `aggregateRating` from JSON-LD. Keep the visible Trust Strip linking to the actual Google profile.

### C3. FAQPage missing on two posts that should have it
`/blog/inp-core-web-vitals-react-debugging-guide` and `/blog/pillar-cluster-content-architecture-modern-seo` carry HowTo + BlogPosting + Breadcrumb but **no FAQPage**, while every other backfilled post does. Root cause is in `scripts/backfill_faq_howto.py`: in `--howto-add` mode the FAQ-injection branch is skipped, and the normal branch later early-returns because HowTo is now present.

**Fix:** Add a `--faq-only` mode (or a `force_faq` flag that bypasses the HowTo presence check) and re-run on those two slugs.

### C4. Duplicate `BreadcrumbList` on `/blog`
Two identical JSON-LD blocks declare the same breadcrumb. GSC will flag this. Remove the standalone block, keep the one inside the `@graph` array.

## HIGH — fix this sprint

### H1. No named human author anywhere
All 33 `BlogPosting` schemas use `"author": {"@type":"Person","name":"SARVAYA Editorial Team","url":"https://sarvaya.in"}`. Type=Person but URL=org homepage is a mismatch; "Editorial Team" isn't an entity for E-E-A-T scoring. No visible byline on article body either. **Single highest-leverage E-E-A-T move.**

**Fix:** Add `Person` schema for Dev Sharma (LinkedIn in `sameAs`, `worksFor → /#organization`); switch every post's `author` to that `@id`; render a visible byline + bio card in the article body.

### H2. No `/about` or team page
Founder is named only in `llms.txt`. For a professional-services agency, the people-behind-the-business gap is a hard QRG trust ding.

**Fix:** Ship a minimal `/about` with founder bio, photo (or initials), credentials, LinkedIn. Add to nav.

### H3. Homepage metric counters render as `0` to crawlers
Counters use `data-target="99"` etc. with JS animation; static HTML contains no `99%`/`45+`/`100%` text. AI engines and Google's text extractor see zeros on the most credibility-laden section. Doubly embarrassing for an agency selling GEO.

**Fix:** Hardcode the visible numbers in `<span>`; let JS read the existing text and animate from 0 to that value.

### H4. Address is country-only
`PostalAddress` carries only `addressCountry: IN`. Add city/state (Jaipur, Rajasthan) on schema and on the contact page — meaningful trust + entity signal.

### H5. No measurable outcomes on `/portfolio`
14 cards, zero numbers, "all NDA". Get written permission for 2–3 quantified blurbs ("Lighthouse 58→94", "leads +30% in 60 days") even without full case studies. Without that, portfolio is weak Experience evidence.

### H6. Lenis loaded from unpkg + 520 ms artificial nav delay
The page-transition handler does `setTimeout(()=>{ location.href=href }, 520)` on every internal link → INP for navigation is **structurally floored at 520 ms**. Lenis is fetched from `unpkg.com` at runtime — uncached third-party with no SLA, blocking scroll init.

**Fix:** Self-host Lenis under `/js/`. Cut the leave-animation timeout to ≤100 ms, or migrate to `document.startViewTransition()`.

### H7. Two perpetual rAF loops on every page
Custom-cursor `animateRing()` + Lenis `raf` both run unconditionally at 60 fps even on hidden tabs and idle pages. Direct INP risk on mid-range Android.

**Fix:** Pause both on `visibilitychange:hidden`; gate the cursor loop on a `mousemove` dirty flag with a 2 s idle stop.

### H8. Stale year copy in `/blog/seo-in-2026`
Body and cover image alt text reference "2025" multiple times despite the URL/title being 2026. Find/replace `2025` → `2026`; update alt text.
